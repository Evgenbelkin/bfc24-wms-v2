УСТАНОВКА НЕСКОЛЬКИХ АГЕНТОВ НА ОДНОМ КОМПЬЮТЕРЕ (ХАБ) — по шагам
====================================================================

Этот способ — для случая, когда к одному компьютеру подключено сразу
НЕСКОЛЬКО принтеров одновременно (например, компьютер стоит в углу зоны
сборки, а через Ethernet-хаб к нему тянутся 5-10 принтеров разных столов).
Если на компьютере всего ОДИН принтер — этот файл не нужен, используйте
обычный install.bat и ИНСТРУКЦИЯ.txt рядом.

Каждый принтер по-прежнему обслуживается своим отдельным процессом-агентом
(1 принтер = 1 ключ = 1 процесс) — просто вместо ручной установки по одному
этот скрипт делает всё сразу списком и оформляет каждый процесс как службу
Windows, которая сама перезапускается, если упадёт или компьютер перезагрузят.

1. Скопируйте всю папку printer-agent на компьютер-хаб — например, на
   Рабочий стол.

2. Скачайте nssm (бесплатная утилита для служб Windows, используется тысячами
   проектов): https://nssm.cc/download — возьмите архив, распакуйте, из
   папки win64 возьмите файл nssm.exe и положите его прямо в папку
   printer-agent (рядом с agent.js).

3. В WMS откройте Панель принтеров и для каждого принтера, который будет
   подключён к этому компьютеру, нажмите "Выпустить ключ агента" —
   скопируйте каждый ключ (начинается с "pk_"). Если принтеров много и они
   заведены в WMS списком (см. массовый импорт принтеров) — ключи можно
   выгрузить сразу все в одну таблицу, спросите об этом отдельно.

4. В папке printer-agent откройте файл printers.example.csv любым
   текстовым редактором (Блокнот подойдёт), сохраните копию как
   printers.csv в этой же папке, и впишите туда реальные названия столов
   и ключи — по одной строке на принтер:

     name,agent_key
     Стол упаковки 1,pk_101_...
     Стол упаковки 2,pk_102_...

   Названия влияют только на имя папки и службы на этом компьютере — на
   работу самого принтера не влияют, но лучше делать их понятными
   (по названию стола/зоны), чтобы потом было легко найти нужную службу.

5. Если у этого хаба будут термопринтеры этикеток — доустановите SumatraPDF
   ОДИН РАЗ на весь хаб: скачайте
   https://www.sumatrapdfreader.org/dl/rel/3.6.1/SumatraPDF-3.6.1.zip,
   распакуйте, положите SumatraPDF.exe в printer-agent\bin\SumatraPDF.exe.
   Скрипт из шага 6 сам скопирует этот файл во все агенты хаба — доставать
   его для каждого принтера отдельно не нужно.

6. Нажмите Пуск, наберите PowerShell, кликните правой кнопкой по найденному
   результату и выберите "Запустить от имени администратора". В открывшемся
   синем окне перейдите в папку агента и запустите скрипт, например:

     cd Desktop\printer-agent
     Set-ExecutionPolicy -Scope Process Bypass -Force
     .\hub-install.ps1

   "Set-ExecutionPolicy ... Bypass -Force" разрешает выполнение скриптов
   только для этого окна — ничего не меняет в настройках компьютера.

7. Скрипт сам поставит зависимости (один раз), создаст папку instances\ с
   отдельной копией агента под каждый принтер из csv и заведёт каждую как
   отдельную службу Windows (видно в самом конце — "Установлено служб: N").

8. Вернитесь в WMS → Панель принтеров — у каждого принтера должен появиться
   зелёный статус "агент на связи" в течение минуты.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
------------------------
- Открыть службы Windows: Win+R → services.msc → искать по названию
  "BFC24 Printer Agent - <имя>". Можно вручную остановить/запустить/
  посмотреть, не упала ли служба сразу после старта.
- Лог конкретного агента: printer-agent\instances\<имя>\agent.log и
  service.log (второй — то, что видит сама служба Windows, включая ошибки
  запуска).
- Добавили новый принтер на этот же хаб или поменяли ключ — допишите/
  исправьте строку в printers.csv и запустите hub-install.ps1 ещё раз
  (от администратора) — повторный запуск безопасен, старые службы просто
  переустановятся.
- Нужно снести все агенты этого хаба (переустановка с нуля, компьютер
  выводится из эксплуатации) — запустите hub-uninstall.ps1 от имени
  администратора.
- Общие проблемы с самой печатью (принтер не печатает, кривой стикер и т.п.)
  — см. раздел "ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ" в обычной ИНСТРУКЦИЯ.txt, он
  актуален и для агентов на хабе.
