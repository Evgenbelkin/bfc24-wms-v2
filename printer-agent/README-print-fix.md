# Фикс кривой автопечати стикеров (SumatraPDF autorotate + default paper size)

## Что произошло

Печать через агента иногда выходила кривой/обрезанной, хотя PDF-файл (проверяли
напрямую) всегда идеальный, и печать того же файла руками через браузер тоже
всегда идеальна. Разобрали проблему с ChatGPT — вывод: старая версия SumatraPDF
(3.4.6, зашита внутри библиотеки `pdf-to-printer`) имеет свою логику
автоповорота страницы, которая срабатывает поверх текущего состояния драйвера
принтера — а это состояние не всегда успевает "устаканиться" одинаково на
первом задании и при повторе. В версии 3.4.6 нет способа эту логику отключить
(флаг `disable-auto-rotation` появился только в 3.5+).

## Что нужно сделать один раз на складском ПК

### 1. Скачать новый SumatraPDF

Скачай портативную версию (32-bit, .zip, без установки) отсюда:

https://www.sumatrapdfreader.org/dl/rel/3.6.1/SumatraPDF-3.6.1.zip

Распакуй архив, найди внутри файл `SumatraPDF.exe` и положи его в папку
агента:

```
Агент печати\bin\SumatraPDF.exe
```

(папку `bin` создай, если её нет). Агент сам обнаружит этот файл и начнёт
использовать его вместо старого встроенного — ничего больше настраивать в
коде не нужно.

Если файл не положить — агент продолжит работать по-старому (со старым
SumatraPDF 3.4.6), просто без этого улучшения.

### 2. Настроить формат бумаги "58x40" как default в ДВУХ местах Windows

Раньше агент сам указывал размер бумаги при каждой печати — отказались от
этого (мешало больше, чем помогало). Теперь формат должен быть настроен
как default прямо в Windows, и агент его вообще не трогает.

В Windows есть ДВА разных места с настройками печати для одного принтера —
это два независимых набора значений, и важно поменять ОБА, не только один:

**Место 1 — Printing Preferences (настройки печати):**
1. Параметры → Устройства → Принтеры и сканеры → найти принтер → «Управление»
2. «Настройка печати» (Printing Preferences)
3. Stock/Name → выбрать `58x40(58.0 mm x 40.0 mm)`
4. Применить → ОК

**Место 2 — Printing Defaults (параметры печати по умолчанию), отдельно от места 1:**
1. Там же → «Свойства принтера» (Printer properties, НЕ то же самое, что
   «Настройка печати» из пункта выше)
2. Вкладка «Дополнительно» (Advanced)
3. Кнопка «Параметры печати по умолчанию» (Printing Defaults)
4. Stock/Name → выбрать `58x40(58.0 mm x 40.0 mm)`
5. Применить → ОК

Второе место (Printing Defaults) — то, что реально используется при печати
"в фоне", без интерактивного диалога (как это делает наш агент). Если
поменять только первое место, второе может остаться со старым форматом —
именно это, предположительно, и объясняло нестабильность.

### 3. Перезапустить агента

Скачать заново `printer-agent.zip` с сайта WMS, распаковать поверх (папка
`bin/SumatraPDF.exe`, если её туда положили, не пострадает — она не входит
в zip с сайта, это отдельный ручной шаг). Убить все `node.exe` в диспетчере
задач или перезагрузить компьютер, запустить `install.bat` заново.

### 4. Проверить

Напечатать через сканирование (не через браузер) минимум 5-10 раз подряд
(в том числе с паузами в несколько минут между печатями) — если ни разу не
съехало и не развернулось, фикс сработал.
